Configura Gemini API
MEDPEDIA usa Google Gemini per generare le schede mediche. È gratuito — nessuna carta richiesta.
1
Vai su aistudio.google.com/app/apikey
2
Accedi con Google → clicca "Create API key"
3
Copia la chiave e incollala qui sotto
🔒 La chiave viene salvata solo nel tuo browser (localStorage). Non viene mai inviata a server terzi.
